## Reproducible Code for "Dynamic Risk Assessment by Landmark Modeling of the Restricted Residual Mean Survival Time"

Authors: Y. Zhang and D. E. Schaubel

Code was written by Y. Zhang. Please address all questions or comments to yzhang@uthsc.edu.

This repository includes R programming scripts for generating the main results in the manuscript. It comprises two subfolders: simulation and application.

### Simulation
For the results in Section 4 of the main manuscript, the documents `sim_nph_add.r` and `sim_ph_add.r` produce Table 1, and the documents `sim_nph_multi.r` and `sim_ph_multi.r` produce Table 2.

### Application
For the results in Section 5 of the main manuscript, the document `analysis.r` produces Table 3, and the document `plot.r` produces Figure 2. The document `concordance.r` calculates the C-index of the proposed predictive model.
