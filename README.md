## Reproducible R code for "Dynamic Risk Assessment by Landmark Modeling of the Restricted Residual Mean Survival Time"

Authors: Y. Zhang and D. E. Schaubel

Code was written by Y. Zhang. Please address all questions or comments to yzhang@uthsc.edu.

This repository includes R programming scripts for generating the main results in the manuscript. It comprises two subfolders: simulation and application.

### Simulation
The documents `sim_nph_add.R` and `sim_ph_add.R` produce Table 1 of the main manuscript. The documents `sim_nph_multi.r` and `sim_ph_multi.r` produce Table 2.
